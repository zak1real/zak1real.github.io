# Портфолио — мои проекты

Статический сайт со списком проектов. Чистые HTML, CSS и JavaScript, без сборки и зависимостей. Тёмная/светлая тема включается автоматически по настройкам системы.

## Запуск

Откройте `index.html` в браузере. Или через локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

## Структура

```
.
├── index.html       # Главная: о себе, разделы «Сайты» и «Telegram-приложения», контакты
├── project.html     # Страница проекта: project.html?id=<slug>
├── css/style.css    # Стили
├── js/
│   ├── projects.js  # ДАННЫЕ: владелец (OWNER) и проекты (PROJECTS)
│   └── main.js      # Рендер главной и страницы проекта
├── assets/          # Скриншоты проектов: <name>.jpg — десктоп, <name>-m.jpg — телефон
├── tools/
│   └── screenshots.mjs  # Съёмка скриншотов (на сайт загружать не нужно)
└── commands.txt     # Шпаргалка с командами (на сайт загружать не нужно)
```

## Как изменить информацию о себе

В [js/projects.js](js/projects.js) отредактируйте `window.OWNER`: имя, роль, короткий текст «о себе» и список контактов.

## Форма «Связаться»

Кнопка «Связаться» в подвале (и любой элемент с атрибутом `data-contact-open`) открывает всплывающую форму. Окно создаётся в [js/main.js](js/main.js) на нативном `<dialog>`, закрывается по Esc, крестику или клику по фону.

Посетитель выбирает, как с ним связаться: **Telegram** или **Email**. Поле контакта меняет подсказку и проверку под выбранный вариант (настройки — объект `CONTACT_TYPES` в `main.js`); ник Telegram приводится к виду `@username`. В письме приходят поля `contact_type` и `contact`.

Отправка идёт через сервис [Web3Forms](https://web3forms.com) (`OWNER.formEndpoint`), письма приходят на почту, к которой привязан ключ:

- **Ключ:** на web3forms.com введите свою почту → «Create Access Key» → ключ придёт письмом. Вставьте его в `OWNER.formAccessKey` в [js/projects.js](js/projects.js). Ключ публичный, хранить его в коде можно. Бесплатно — 250 писем в месяц.
- Раньше использовался FormSubmit, но `formsubmit.co` из России не открывается (соединение висит до таймаута) — у посетителей форма не работала бы.
- Скрытое поле `_honey` отсекает простых спам-ботов.
- Если сервис недоступен или ключ пустой, форма открывает почтовый клиент посетителя с заполненным письмом на `OWNER.email`.

## Как добавить проект

1. Снимите скриншоты (см. ниже) — в `assets/` появятся десктопная и мобильная версии.
2. Добавьте объект в `window.PROJECTS` в [js/projects.js](js/projects.js):

```js
{
    slug: "my-project",          // в адресе: project.html?id=my-project
    type: "site",                // раздел на главной: "site" (по умолчанию) или "telegram"
    title: "Название",
    subtitle: "Что это за сайт",
    year: "2026",
    status: "done",              // "done" — готово, "wip" — в разработке; без поля бейдж не показывается
    cover: "assets/my-project.jpg",   // обложка карточки на главной
    gallery: [
        // src — десктоп, mobile — телефон (необязательно)
        { src: "assets/my-project.jpg", mobile: "assets/my-project-m.jpg", caption: "Подпись к скриншоту" }
    ],
    description: [
        "Первый абзац описания.",
        "Второй абзац."
    ],
    role: "Что делали лично вы",
    stack: ["HTML", "CSS", "JavaScript"],
    links: {
        demo: "https://...",     // живой сайт; пусто — кнопка не показывается
        code: "https://github.com/..."  // репозиторий; пусто — кнопка не показывается
    }
}
```

Порядок в массиве = порядок на сайте. Если `id` в адресе не найден, открывается первый проект.

### Разделы и Telegram-проекты

На главной проекты разбиты на разделы по полю `type`: каждая сетка `<div data-project-grid="тип">` в [index.html](index.html) показывает проекты своего типа. Раздел без проектов скрывается. Новый раздел — это ещё одна такая секция с новым типом и ссылкой в шапке.

У Telegram-приложений нет десктопной версии, поэтому в `gallery` у них только `mobile`, без `src`, а `cover` не указывается:

```js
{
    slug: "tg-shop",
    type: "telegram",
    // ...
    gallery: [
        { mobile: "assets/tgshop-catalog-m.jpg", caption: "Каталог" },
        { mobile: "assets/tgshop-cart-m.jpg", caption: "Корзина" }
    ],
    links: { demo: "https://t.me/<бот>" }   // кнопка «Открыть в Telegram»
}
```

Такие кадры на странице проекта идут рядом в ряд телефонов, а обложкой карточки становятся первые три из них.

На главной в каждом разделе сразу видны первые 3 проекта, остальные открываются кнопкой «Ещё» (и сворачиваются обратно кнопкой «Свернуть»). Число задаётся константой `VISIBLE_PROJECTS` в [js/main.js](js/main.js). Если проектов не больше этого числа, кнопки нет. Важные для клиентов проекты ставьте в начало массива — они будут видны без нажатия.

Статус показывается бейджем на обложке карточки и под заголовком на странице проекта. Тексты бейджей — объект `STATUSES` в [js/main.js](js/main.js).

Если у кадра галереи есть `mobile`, на странице проекта десктоп и телефон показываются рядом (на узких экранах — друг под другом), а на обложке карточки появляется мини-телефон с мобильной версией обложки.

### Скриншоты

Скрипт [tools/screenshots.mjs](tools/screenshots.mjs) снимает каждую страницу дважды: десктоп 1440×900 и телефон 390×844 (iPhone, плотность 2x), в JPEG. Нужны Node.js 22+ и Google Chrome. Проекты должны лежать рядом с папкой `portfolio`.

1. Добавьте страницу в массив `SHOTS` в начале скрипта: `name` — имя файла, `page` — путь от папки с проектами (можно с `?id=...`), `scroll` — селектор блока, если нужен не первый экран. Для мобильных интерфейсов (Telegram-приложения) есть ещё:
   - `mobileOnly: true` — снимать только телефон;
   - `action` — JS, который выполняется на странице перед снимком, чтобы показать нужное состояние (открыть карточку, наполнить корзину, заполнить форму). Внутри доступны `click(селектор)`, `type(селектор, текст)` и `await wait(мс)`. Перед каждым снимком localStorage очищается, так что корзина из прошлого снимка не мешает. Примеры — кадры `tgshop-*`.
2. Запустите из папки `portfolio`:

```powershell
node tools/screenshots.mjs            # все скриншоты
node tools/screenshots.mjs dimzerz    # только те, в имени которых есть «dimzerz»
```

Страницы открываются через встроенный локальный http-сервер, а не как файлы (`file://`) — так сайты ведут себя как на хостинге (например, YouTube-встраивания в `file://` не работают). Скрипт ждёт загрузки шрифтов и первого кадра видео и предупреждает, если у страницы есть горизонтальный скролл. Для превью YouTube и Google Fonts нужен интернет. Обычный `chrome --headless --window-size=390,...` для телефона не подходит: на Windows окно не становится уже ~500px, и вёрстка снимается не мобильная.

## Публикация

Подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel): загрузите содержимое папки как есть.

Сайт опубликован на GitHub Pages: репозиторий `zak1real.github.io`, адрес https://zak1real.github.io.

**Как обновить сайт** (через github.com, без git): откройте репозиторий → **Add file → Upload files** → перетащите изменённые файлы или папки (`js`, `css`, `assets`…) → **Commit changes**. Файлы с тем же именем заменятся, через 1–2 минуты изменения появятся на сайте.
